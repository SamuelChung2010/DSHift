# DSHift 用户指南

本文覆盖 Chat 模式的日常使用：安装、切换、输入、附件、会话管理、Chat → Agent 交接、聊天记录导入和长期记忆。安装与认证的底层配置见 [配置说明](configuration.md)；完整功能边界见 [已知限制](limitations.md)。

## 安装与首次启动

前置条件：DeepSeek Harness `>=0.2.2-rc.5`，以及已登录的 DeepSeek 账号或 API Key。

```sh
dsh plugin add github:SamuelChung2010/DSHift
```

也可以在 DSH 的 **Plugins** 页面选择本仓库目录，或安装 GitHub Release 中的 `.tgz`。`.zip` 需要先解压，再选择解压后的目录。安装 Host 端后重启 DSH 或重载插件；浏览器端首次可能提示刷新。

第一次打开 Chat 时，在 **Chat 设置 → 认证** 中选择使用 DSH 账号或 API Key。默认认证顺序和更多选项见 [配置说明](configuration.md#认证)。

## Chat 与 Agent 切换

应用顶部（Windows 标题栏 / macOS 顶栏）居中是共享的 **Chat | Agent** 分段控件：

- **Chat**：DSHift 的对话界面，有独立历史、输入框和搜索。
- **Agent**：Harness 原生 Agent 界面。

两边的会话、工作区和未发送草稿分别保留，切换不会清空任何一侧。

### 显示规则

- 只在空白页显示：Chat 中还没有消息的新对话，或 Agent 中没有会话 / 仍是空白会话的页面。
- 发送第一条消息（不必等回答）或进入已有会话后自动隐藏；进入其它已有会话也保持隐藏。
- 点 Chat 的「新对话」或 Agent 的「新会话」回到空白页时，切换器再次出现。
- Chat 的空白判断读取消息模型与会话摘要，不依赖 DOM；加载中的会话按摘要的消息数判断，避免闪烁。
- 隐藏时不渲染元素，不会留下透明遮挡层，底层按钮仍可点击。

切换器是不对称分段控件：选中的一侧占约 55%，未选中侧约占 45%，滑动时底座中心保持不变。水平方向按当前模式的主内容列居中，垂直方向对齐 Agent 页面右上角原生工具按钮的中心线；侧栏宽度变化后会重新居中。

### 侧栏与窗口适配

- Chat 侧栏与原生 Agent 侧栏同构：DeepSeek 鲸鱼 + `deepseek` 字标、新对话、搜索、历史列表、底部设置。
- 拖拽侧栏右边缘可在 264–420px 之间调整宽度；宽度写入本机偏好，重启后保留。窗口过窄时优先保证聊天列可读。
- 自动收起断点与 Harness 一致（1024px）。macOS 下侧栏材质、分隔线、原生按钮让位和发送键文案都做了对应适配。

## 首页与会话侧栏

空白首页只有一条欢迎语和输入框，不堆叠功能卡片。12 句不同风格的问候按「新建对话」随机轮换，同一页内保持不变且不会连续重复；带用户名的句子会读取当前 DSH / DeepSeek 账号的显示名称，取不到时使用不带称呼的版本。

侧栏支持：

- 新建对话、搜索历史、打开设置。
- 置顶 / 取消置顶：置顶会话集中在「已置顶」区域，按最近活动排序。
- 文件夹：创建、重命名、删除、折叠/展开（折叠状态持久化）；把一条或多条会话移入/移出文件夹。删除文件夹只把会话移回未分类，不删除聊天记录。
- 归档：从普通历史隐藏，在「归档管理」中查看、恢复或删除。
- 右键或「···」菜单集中提供重命名、置顶、移动、归档、删除；删除会话与文件夹都有确认。
- 历史搜索同时搜索标题和消息正文，支持中英文；结果显示正文片段、置顶/归档标记，点击打开会话并定位到匹配消息（包括旧分支）。

## 输入框与发送

- 输入框是一个统一的圆角面板，编辑器本身无边框、无浏览器焦点方框；随文本自动增高，超过 220px 后在内部滚动。
- 默认 **Enter 发送、Shift + Enter 换行**；可在设置中改为 **Ctrl / Cmd + Enter 发送**。
- 中文、日文输入法组合文字时，Enter 只确认候选，不会误发。
- 未发送草稿按会话暂存：切换会话或点「新对话」时恢复各自的文本；附件上传会按原有逻辑中止。
- 输入框下方固定位置的联网搜索与深度思考是独立开关；推理等级属于右侧模型座位，不额外占用触发器。
- 窄窗口下工具按钮收为图标、工具行允许换行，不产生横向溢出。

## 工具菜单与能力

输入框左下的 **＋** 是工具入口：

- 面板向上浮出，与输入框几乎等宽、间隔 4px；行式布局为左侧图标 + 名称、右侧简短说明。
- 支持键盘方向键 / Home / End / Escape 操作，空间不足时自动翻到另一侧并限制高度。
- 当前内置上传图片/文件；联网搜索与深度思考是输入框旁的直接按钮，不重复出现在菜单里。

### 联网搜索

使用 DeepSeek 服务端 `deepseek_web_search`。回答带正文引用编号和可折叠来源列表；链接会自动声明 `deepseek_read_url` 让模型阅读用户消息中的链接。联网搜索是否可用取决于账号/API Key 与模型能力，可能产生额外用量费用。

### 深度思考

展示可折叠的思考过程与固定用时（刷新、切换会话后不再增长）。推理等级与模型一起在右侧模型座位中选择 `Off / Low / High / Max`；设置与输入框下方的深度思考按钮共享。

### 模型选择

- 可选 `deepseek-flash`（DeepSeek-V4.1-Flash）与 `deepseek-v4-pro`（DeepSeek-V4-Pro）。
- 右侧显示类似原生的 `DeepSeek-V4.1-Flash Max`；展开后先看到「模型 / 推理等级」两行，再进入模型列表或档位列表，当前项用右侧勾选标记。
- 模型菜单不铺长说明或能力标签；完整说明只放在行的 `title` 里。唯一例外是会影响附件操作的限制（如 V4 Pro「不支持图片」），以一行小字显示。
- 选择按会话保存；新对话使用全局默认。模型目录由 Host 提供，浏览器不猜测列表。
- 不支持的能力会禁用并在行内说明。`deepseek-v4-pro` 不支持图片理解；含图片的消息会在发送前被拒绝并提示切换模型。

## 文件与图片上传

- **PDF、Word、PowerPoint**：走版面解析。
- **图片**：作为图片输入（需要所选模型支持）。
- **文本、代码、表格、电子书** 等：走 `user_data`。
- 上传通过 Harness 原生文件选择器；支持点击、拖拽与粘贴。单个文件默认上限 64 MB（可在 Host 配置中调整）。
- 附件会随编辑后的用户消息保留；上传由 DeepSeek Files API 托管，插件只保存 `file_id` 与展示元数据。

## 消息操作

- **普通对话**：多轮上下文、流式输出、停止生成；停止后可继续生成或重新生成。
- **编辑用户消息**：悬停显示编辑/复制。编辑框沿用消息气泡样式（无嵌套边框），Enter 保存并发送、Shift + Enter 换行、Esc 取消。编辑会创建新分支，原回答与后续对话保留为版本，模型只接收当前分支上下文。
- **回答操作**：复制、重新生成。重新生成产生独立版本（`1 / 3` 切换）；用户消息的编辑版本也可切回。每个版本各自保存正文、思考块、引用来源、用量与结束原因。
- **继续生成**：用户主动停止、网络中断、超时或 `max_tokens` 截断的回答，可从已有正文处继续（assistant 前缀续写，不做无关拼接）。只对当前最后一条有正文的回答开放；续写不会恢复深度思考。
- 生成过程中需要先停止回答，才能切换会话、编辑消息或新建对话。

## 来源与引用

- 正文里的引用是编号胶囊，点击打开原始网页。编号由来源收集逻辑生成：先按引用顺序给被引页面编号，再追加未被引用的搜索结果；按 URL 去重且不改变已分配编号，刷新历史后编号与链接仍对应。
- 来源默认折叠为一行 `来源 · N`，展开后是单列紧凑列表（编号、标题、域名、可选摘要），有最大高度并内部滚动。
- 来源为零时不渲染来源组件；思考区、正文、来源使用不同字号与颜色权重。

## 内容渲染

- **代码高亮**：语言标识、一键复制、长代码内部滚动、明暗两套配色；支持 JS/TS、JSON、HTML/XML、CSS、Python、Bash、PowerShell、SQL、Java、C#、C/C++、Go、Rust、YAML、Markdown、diff 等，未知语言按纯文本显示。
- **LaTeX**：行内与独立公式块，支持分数、根式、上下标、大型运算符、定界符、矩阵、cases/aligned、重音、希腊字母、`\boxed{}`、`\qquad` 和顶层 `\\` 换行。是面向聊天的子集，不是完整 KaTeX；未知命令或未闭合环境会整条回退为浅底等宽源码，不丢字、不报错。
- **Mermaid**：flowchart/graph、sequenceDiagram、pie、classDiagram 的 React SVG 渲染；不支持或超出上限时显示错误说明并保留源代码。
- **其它**：表格、引用块、超链接、图片；所有内容以 React 元素输出，不使用 `innerHTML` / `eval`，链接与图片只允许 http(s)。
- 流式输出时已完成的块跳过重渲染；未闭合的块级公式或 TeX 围栏先显示同尺寸源码块，闭合后整体替换。

## Chat → Agent 交接

1. 在 Chat 里讨论完需求，点右上角 **交给 Agent**。
2. Host 用 DeepSeek 把对话整理成任务说明；模型不可用时退回本地整理的版本，仍可编辑。
3. 选择工作区：直接选已有工作区，或选 **＋ 新建工作区…** 填名称、选项目文件夹。**选择已有目录…** 把所选目录当作项目文件夹；**在此新建文件夹…** 把所选目录当作上级目录，按名称创建（目录不存在会自动创建）。也可以粘贴完整绝对路径。
4. 如果对话看起来是新项目且当前工作区与标题无关联，会出现一条不阻断操作的提示，可一键打开带名称建议的新建面板。
5. 确认后创建新的 Agent 会话，把任务说明作为首条提示提交，自动切换到 Agent 并打开该会话。

交接走 Harness 原生机制：`ctx.sessionController.create()` + `prompt()` 建立会话，浏览器侧用 `ctx.uiWorkspace.openSession()` 打开；新建工作区通过原生目录选择器和 Host 的 `/api/deepseek-chat/workspace` 建目录并调用 `ctx.workspaceRegistry.create()` 注册，不复制独立的工作区存储。

## 导入 DeepSeek 聊天记录

侧栏底部 **导入聊天记录** 把 DeepSeek App / 网页版导出的 ZIP 合并进 Chat 历史：

1. 选择或拖入 ZIP（如 `deepseek_data-<导出日期>.zip`）。文件只交给本地 Host 解析；不上传、不调用 DeepSeek API。
2. 预览列出全部会话：标题、创建时间、消息数。已导入的标为「已导入」并默认不勾选；可按标题筛选、全选或逐个勾选。
3. 导入在 Host 后台进行，弹窗显示进度并可随时取消；单个会话出错只进入失败列表，不影响其他会话。
4. 结束后显示成功 / 跳过 / 失败数量并刷新侧栏。导入的会话就是普通 Chat 历史：可以阅读、搜索、重命名、置顶、归档、移入文件夹、切换消息版本，也可以继续对话或交给 Agent。

这是合并导入，不是覆盖。每条导入会话带稳定来源 `source = { kind: 'deepseek-export', id, importedAt }`；同一份导出（或包含同一会话的另一份导出）再次导入时会跳过已存在会话。写入前把当前 `state.json` 复制为 `state.json.import-backup-<时间戳>`；历史按批写入，中断或取消时只有已完成批次留在文件中。

### 支持范围

| 导出内容 | 导入结果 |
| --- | --- |
| 标题、创建 / 更新时间、置顶 | 原样保留（标题为空时用第一条提问补全） |
| 用户提问、AI 回答、Markdown / 代码 / 公式 | 原样保留，沿用现有渲染 |
| 深度思考 `THINK` | 思考块，按导出的 `elapsed_secs` 还原用时 |
| 联网搜索 `TOOL_SEARCH` / 打开网页 `TOOL_OPEN` | 「搜索 / 阅读」步骤 + 搜索结果与来源列表 |
| 内容风险提示 `CONTENT_RISK` | 回答下方的提示条，不进入正文、复制内容或模型上下文 |
| 文件 / 图片 `FILE` | 附件元数据；图片字节从 ZIP 恢复并保存在本地，可直接显示 |
| 消息分支（编辑提问 / 重新生成） | 完整节点树；`current_message_id` 作为当前分支，其他版本仍可切换 |
| 未完成 / 超时 / 被内容过滤的回答 | 保留原状态与服务器模板文案，不伪造内容 |
| `TOOL_FIND`、`TOOL_IMAGE_SEARCH` 等片段 | 不导入（导出中没有可还原的正文） |

### 安全与限制

- ZIP 由 Node 内置 `zlib` 读取：只按名字取需要的条目，从不把条目名当作路径写文件；限制归档大小、条目数量与单条目解压上限，校验 CRC 与声明大小；拒绝 ZIP64、加密条目和多卷压缩包。
- 解析与转换都在 Host 进程内，按会话逐个进行并让出事件循环；同一时间只允许一个导入任务，浏览器轮询进度，可随时取消。
- 只接受 `export_format_version: 3`；遇到新版本会明确提示「不支持的导出格式」，不猜测解析。
- 图片只恢复 PNG / JPEG / WebP / GIF / BMP / AVIF / SVG；导出中缺少字节的附件只保留名称、大小与类型。
- 导入的本地图片不会重新上传到 DeepSeek，因此继续对话时模型看不到这些图片（历史文字与回答照常参与上下文）。
- 导入大量会话会让 `state.json` 变大；每次保存重写整份文档，建议只勾选需要的会话。可导入会话超过 100 个时弹窗会提示。

## 长期记忆

**Chat 设置 → 长期记忆** 是一套与会话历史分开的本地记忆系统。记忆默认开启、自动提取默认关闭，两者都可随时切换。

- **自动记忆提取**（需主动开启）：一轮对话结束后，Host 先用本地规则判断是否包含值得长期保存的信息（明确指令、语言/格式/工具习惯、长期背景、项目与技术栈、重要决定等），只有通过判断的轮次才调用一次 DeepSeek 提取；普通闲聊、代码问答和短句不会产生额外请求，每个会话有轮次与时间节流。开启前提示相关内容会发送到 DeepSeek API、可能产生费用。密码、证件号、银行卡、精确住址、联系方式等敏感个人信息不会被自动保存。
- **跨会话检索**：每次请求在 Host 端按当前问题做本地词法相关度选择，不引入向量数据库或 Embedding；只把少量相关记忆加入上下文，并限制条数与字符预算。新指令优先于历史偏好，记忆明确标注为参考信息，不能覆盖系统规则。关闭长期记忆后，检索、注入和自动提取全部停止。
- **记忆概述**：把单条记忆整理成自然、分类清晰的概述，显示最后更新时间。概述是派生缓存：只有记忆条目实质内容变化（修订号增加）才标记过期，打开记忆页或点「重新整理」时才重新生成，不会每轮聊天都调用模型。
- **Ask or Update**：用自然语言查询（“你现在记得我哪些事情”）、新增、更正、删除，或重新整理概述。新增、更新、删除会真正写入本地存储；删除目标不明确时先列出候选并要求确认，不会误删其他记忆。
- **管理与隐私**：按分类筛选，手动新增、编辑、删除，清空全部（需确认）；每条记忆记录来源（手动 / 来自对话 / 导入自 ChatGPT、Claude、Gemini 等）与更新时间。删除会留下墓碑，旧聊天之后的自动提取不能把它加回来。
- **从其他 AI 导入**：两步式弹窗。第一步复制一段英文、与平台无关的导出提示词发给其他 AI（Instructions / Identity / Career / Projects / Preferences 五类，每条 `[YYYY-MM-DD] - 内容`，未知日期用 `[unknown]`，整个结果放在单个代码块里）；第二步把结果粘贴回来，本地解析、预览、编辑、勾选后合并导入。重复、冲突或可能包含敏感信息的条目会被标记，并允许逐条选择跳过、合并或更新；重复粘贴同一份导出不会产生重复记忆。非结构化文本可以显式同意后交给 DeepSeek 整理，默认不发送。

### 与聊天记录导入联动

导入完成页会出现可选的「提取长期记忆」入口，也可以在「长期记忆」页重新打开。弹窗先列出可分析的导入会话（已分析过的带标记、默认跳过），默认不勾选任何会话；勾选后说明每个会话一次额外 API 调用及可能费用，只有再次确认后才逐个调用 `extract.imported`（一次最多 20 个，超出会明确提示而不是静默截断；分析过程中显示进度，可在会话之间停止）。

候选记忆沿用预览的重复/冲突标记（提取阶段已过滤敏感信息），确认后走同一个 `import` 合并入口，来源记为「来自对话」。分析只读取当前分支消息，不修改 `state.json` 的消息树；成功时间写入会话 `source.memoryExtractedAt`，同一批历史不会重复发送，除非显式勾选「重新分析」（关闭预览不会撤销标记，界面会提示）。接口契约见 [长期记忆集成](memory-integration.md)。

## 认证

Chat 模式不会把 API Key 写进代码或配置文件，按顺序自动选择：

1. Chat 设置中保存的 API Key（保存在 DSH 凭证库，键名 `DEEPSEEK_CHAT_API_KEY`）
2. DSH 凭证库 / 环境变量中的 `DEEPSEEK_API_KEY`
3. DSH 已登录的 DeepSeek 账号令牌（`ctx.deepseekAccount`，走 `x-dsh-auth-token`）

也可以在 Chat 设置中强制选择 **DSH 账号** 或 **API Key**。API Key 只在 Host 进程内使用，不会发送到浏览器。详见 [配置说明](configuration.md#认证)。

## 主题、语言与快捷键

- 中英文界面、明暗主题跟随 DSH 设置；窗口缩放和窄屏/移动端布局会调整侧栏与工具行。
- 默认 Enter 发送、Shift + Enter 换行；设置中可改为 Ctrl / Cmd + Enter 发送。
- macOS 的发送快捷键提示显示 Command + Enter。
- 生成过程中先停止回答，才能切换会话、编辑消息或新建对话。
