# 已知限制

DSHift 仍是 beta。本文列出兼容性、功能边界、性能测试范围和数据限制；安装与使用见 [README](../README.md) 和 [用户指南](user-guide.md)。

## 兼容性与平台

- 本版本在 **DeepSeek Harness 0.2.2-rc.5** 上验证：Windows Desktop 与 macOS 的界面修复均已实机核对；`engines.dsh` 声明为 `>=0.2.2-rc.5`。
- **Web 端尚未验证**；浏览器首次加载或插件更新后可能提示刷新。
- 性能基准只在 Windows 11 + Chrome 158 headless 上完成；macOS、Electron 桌面窗口内的绝对延迟未单独测量。
- 本插件不是 DeepSeek 官方产品，也不代表 DeepSeek 的官方推荐或支持。
- 内部包名保持 `@local/deepseek-chat-mode`，数据目录保持 `$DSH_HOME/deepseek-chat/`，以兼容既有安装和历史。

## 功能边界

- **数学公式**：面向聊天的 LaTeX 子集（不是完整 KaTeX）；`\begin{tikzcd}`、自定义宏、`\color` 等高级用法会整条回退为带浅底的等宽源码，不丢字、不报错。
- **Mermaid**：支持流程图、时序图、饼图与基础类图；思维导图、甘特图等类型会显示错误说明并保留源代码。
- **版本管理**：编辑/重新生成采用线性版本导航（`‹ 1 / 3 ›`），不是完整的可视化分支树面板；被替换的分支仍保存并可切换回来。
- **继续生成**：依赖 DeepSeek Messages API 的 assistant 前缀续写（prefill）语义；如果账号或服务端拒绝该模式，请改用重新生成。续写不会恢复深度思考，只延续可见正文。
- **历史搜索**：在本地扫描当前 `state.json` 的全部消息节点，适合本机历史量；没有独立搜索索引服务。
- **文件夹整理**：通过菜单完成，未实现拖拽排序（避免引入拖拽依赖）。
- **生成过程**：需要先停止回复，才能切换会话、编辑消息或新建对话。
- **图片理解**：`deepseek-v4-pro` 不支持图片理解；含图片的消息会在发送前被拒绝并提示切换模型。
- **Host 更新**：`index.js` / `lib/` 改动后需要重载插件或重启 Harness 才会生效；浏览器端会先显示“需要刷新插件”的提示。
- **界面文案**：中英文和明暗主题由 DSH 设置与浏览器偏好驱动；极端窄窗口下布局会自动调整，但不保证所有移动端浏览器。

## 聊天记录导入

- 只接受 DeepSeek 官方导出格式 `export_format_version: 3`；出现新版本时会明确提示「不支持的导出格式」，不会猜测解析。
- 导入大量会话会让 `state.json` 变大（几百个会话约几十 MB），每次保存都要重写整份文档；建议只勾选需要的会话（可导入会话超过 100 个时弹窗会提示）。
- 导入是单任务的：同一时间只允许一个导入任务，取消后会保留已写入的批次。
- 导入只恢复导出中确实存在的内容：`TOOL_FIND` / `TOOL_IMAGE_SEARCH` 等没有正文的片段不会进入消息；导出中缺少字节的附件只保留名称、大小与类型。
- 图片只恢复 PNG / JPEG / WebP / GIF / BMP / AVIF / SVG；导入的本地图片不会重新上传到 DeepSeek，因此继续对话时模型看不到这些图片。
- ZIP 解析限制归档大小、条目数量与单条目解压上限；拒绝 ZIP64、加密条目和多卷压缩包。导入失败只影响当前会话批次，不影响其他会话。

## 长期记忆

- 跨会话检索使用本地词法匹配（中文按二元字符、英文按单词），没有向量数据库或 Embedding；语义相近但用词完全不同的记忆可能检索不到，适合轻量本机使用。
- 自动提取依赖本地规则判断加每轮最多一次额外模型调用；关闭自动提取后手动记忆、检索与导入仍然可用。
- 记忆概述一次生成一种界面语言的文本；切换界面语言后点击「重新整理」才会按新语言重新生成。
- 跨平台导入优先使用本地解析器，支持常见标题、列表与代码块格式；极端格式可能需要「AI 整理」（需显式同意后才会发送到 DeepSeek）。
- 敏感信息检测与去重都是启发式规则，不能替代用户自己检查；导入前预览会标出可能重复、冲突或敏感的内容。
- 长期记忆只保存在本机 DSH Host 的 `memory.json`，不参与 Harness 原生 Agent 会话存储，也不会同步到其他设备。
- 导入后的记忆提取是用户主动发起的：默认不分析任何会话，每个被分析的会话会产生一次额外 DeepSeek 调用与相应费用。成功完成的会话写入 `source.memoryExtractedAt`，下次默认跳过；模型有响应但没有候选时仍算已分析（避免为同一段历史重复付费），没有可分析内容或请求失败的会话不写标记，也不修改已导入的聊天。分析中途停止时，已完成请求的会话保留标记，未开始的保持可分析。
- 密码、证件号、银行卡、精确住址、联系方式等敏感个人信息不会被自动保存；检测是启发式的，不能保证覆盖所有情况。

## 数据、隐私与费用

- 聊天历史、长期记忆、导入暂存与图片保存在本机 `$DSH_HOME/deepseek-chat/`；导入 ZIP 不上传。
- 聊天、联网搜索、文件解析、标题生成和记忆提取会按需调用 DeepSeek API，可能产生用量费用；联网/解析是否可用取决于账号/API Key 与模型的服务端能力。
- 删除会话只删除本地记录和该会话的模型偏好，不删除 DeepSeek 侧已上传的文件。
- 上传文件由 DeepSeek Files API 托管；插件只保存 `file_id` 和展示元数据。
- 备份：v1→v2 迁移前保留 `state.json.v1-backup-*`，导入前保留 `state.json.import-backup-*`；记忆文件损坏时隔离为 `memory.json.corrupt-*` 并从空记忆启动。

## 性能测试边界

- Beta 4 的数据来自 **合成会话**，不是真实用户聊天记录。
- 环境为 Windows 11、Intel Core Ultra 5 228V、31.5 GB、Chrome 158 headless、真实 DSH Web UI；P95 指输入事件到绘制后任务的延迟。
- 500 条密集 Markdown 会话的修复前 P95 为 118.3 ms、修复后 14.5 ms；普通输入时历史消息/Markdown 重渲染为 0。这些是本机结果，不代表所有用户、所有模型/内容或 macOS / Electron 的实际体验。
- 500 条密集内容首次挂载仍约 3 秒，是一次性 DOM/布局成本，不在输入路径；长会话的初始打开速度仍可继续优化。
- 未做真实 IME 硬件交互、弱网、低内存设备或超大附件压力测试；正式使用前建议在目标设备上验证。

## 版本状态

- 当前为 **beta**。安装前备份 DSH profile，先在非关键 profile 中试用。
- 从 `v0.2.0-beta.3` 升级到 `v0.2.0-beta.4` 无数据格式变化，无需迁移；跨大版本升级请先备份 `$DSH_HOME/deepseek-chat/`。
